# دفتر – نظام محاسبة وإدارة (تطبيق مستقل)

هذا المجلد هو نسخة مستقلة من التطبيق يمكن تشغيلها على أي خادم ويب، وتثبيتها على الآيفون كتطبيق على الشاشة الرئيسية.

## محتويات الحزمة
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً (HTML + CSS + JavaScript في ملف واحد) |
| `manifest.webmanifest` | بيانات التطبيق المثبّت (الاسم والأيقونة ولون الشريط) |
| `sw.js` | يحفظ التطبيق للعمل دون اتصال بعد أول فتح |
| `icon-192.png`, `icon-512.png` | أيقونات التطبيق |
| `README.md` | هذا الملف |

## المتطلبات الخارجية
التطبيق يحمّل ثلاثة موارد من الإنترنت لا تدخل ضمن هذه الحزمة:
- مكتبة `html2canvas` من cdnjs، لإنشاء ملفات PDF
- مكتبة `jsPDF` من cdnjs، لإنشاء ملفات PDF
- خط Tajawal من Google Fonts (إن تعذّر تحميله يُستخدم خط النظام)

لذلك يحتاج الجهاز إلى اتصال بالإنترنت عند أول فتح، وتعمل ميزة PDF بعد تحميل المكتبات. لتشغيل كامل بلا إنترنت، حمّل الملفات الثلاثة وضعها بجانب `index.html`، ثم غيّر روابطها في وسم `<head>` إلى المسارات المحلية.

## ملاحظات مهمة عن البيانات
- **الحفظ السحابي غير موجود في هذه النسخة.** النسخة المنشورة على claude.ai تحفظ بيانات كل مستخدم في حسابه، أما هذه النسخة فتحفظ البيانات في متصفح الجهاز فقط (localStorage).
- بيانات التطبيق تُحفظ لكل نطاق (domain) ولكل متصفح على حدة. تطبيق الشاشة الرئيسية على الآيفون له تخزين مستقل عن Safari، فإن أردت نقل بياناتك استخدم **المزيد ← الإعدادات ← نسخة احتياطية** داخل التطبيق (نسخ البيانات واستعادتها).
- تسجيل الدخول بالبريد وكلمة المرور داخل النسخة المنشورة يعتمد على حساب Claude، وهذا غير متاح هنا. في هذه النسخة يعمل قفل كلمة المرور محلياً فقط.

## أولاً: التشغيل محلياً على الكمبيوتر
تحتاج تثبيت Python 3 (أو أي خادم ويب ثابت). لا تفتح `index.html` بالنقر المزدوج، لأن خدمة العمل دون اتصال تعمل فقط عبر `http://localhost` أو `https`.

1. افتح الطرفية (Terminal) داخل مجلد الحزمة.
2. شغّل الخادم:
   ```bash
   python3 -m http.server 8000
   ```
   على Windows استخدم `python -m http.server 8000`.
3. افتح المتصفح على العنوان: `http://localhost:8000/`
4. لإيقاف الخادم اضغط `Ctrl + C`.

## ثانياً: نشر التطبيق على الإنترنت (مطلوب للآيفون)
الآيفون يحتاج رابطاً بـ `https`. يمكنك استخدام أي استضافة ثابتة مجانية، مثل:
- **GitHub Pages:** أنشئ مستودعاً عاماً وارفع الملفات، ثم من Settings ← Pages اختر الفرع `main` والمجلد `/root`. الرابط يكون بصيغة `https://اسمك.github.io/اسم-المستودع/`.
- **Netlify Drop:** اسحب مجلد الحزمة إلى app.netlify.com/drop، فيعطيك رابطاً فوراً.

تأكد أن الملفات كلها في جذر الموقع، وأن `index.html` موجود مباشرة فيه.

## ثالثاً: تثبيت التطبيق على الآيفون
1. افتح الرابط في **Safari** (لا يعمل التثبيت من Chrome على الآيفون).
2. اضغط زر **المشاركة** (المربع مع السهم للأعلى).
3. اختر **إضافة إلى الشاشة الرئيسية**.
4. اسم التطبيق "دفتر" والأيقونة تظهر كأي تطبيق، وعند فتحه يعمل بملء الشاشة دون شريط المتصفح.

## رابعاً: إنشاء تطبيق آيفون حقيقي (اختياري، للمطورين)
الطريقة السابقة تكفي للاستخدام الشخصي. لنشر التطبيق في App Store تحتاج:
1. جهاز Mac وتطبيق Xcode وحساب مطور Apple (99 دولاراً سنوياً).
2. أداة **Capacitor** لتحويل المجلد إلى مشروع iOS. من الطرفية داخل المجلد:
   ```bash
   npm init -y
   npm install @capacitor/core @capacitor/cli @capacitor/ios
   npx cap init دفتر com.example.daftar --web-dir=.
   npx cap add ios
   npx cap open ios
   ```
   ثم من Xcode اختر فريق التوقيع (Signing Team) وشغّل التطبيق على جهاز أو محاكي.
3. لتثبيته على جهازك بدون App Store استخدم TestFlight أو الربط المباشر من Xcode.

هذه الخطوات تنشئ مشروعاً جديداً ولا تغيّر ملفات التطبيق الأصلية.

## استكشاف الأخطاء
- **لا تظهر أزرار PDF:** تأكد من الاتصال بالإنترنت، ثم أعد تحميل الصفحة.
- **لا يظهر خيار "إضافة إلى الشاشة الرئيسية":** افتح الرابط في Safari وليس في تطبيق آخر.
- **البيانات اختفت بعد تغيير الرابط:** البيانات مرتبطة بالنطاق، والرابط الجديد يبدأ بتخزين فارغ.
- **مسح الباركود بالكاميرا لا يعمل على الآيفون:** متصفح Safari لا يدعم هذه الميزة، استخدم الإدخال اليدوي.
